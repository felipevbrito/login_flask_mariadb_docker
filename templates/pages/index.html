O que esse sistema faz?

Já possui:

  • Cadastro de usuário;
  • Validação de segurança;
  • Proteção de URL;
  • Alteração de dados de usuário logado;
  • Verificação de e-mail repetido;
  • Níveis de acesso;
  • Impedir multiplo acesso em dispositivos/navegadores diferentes;
  • Expiração automática de sessão (configuração de 20 min);
  • Paginação vinda do backend;
  • Usuário excluido nao pode fazer login;
  • Forçar reset de senha pelo admin;
  • Impedir o admin de se excluir;
  • Impedir o admin redefinir a própria senha na view;
  • Sistema de HelpDesk (um usuário base relata um erro no próprio sistema);
  • HelpDesk tem numeracao de nao resolvidos (apenas para Admin);
  • HelpDesk pode ser adicionado imagens;
